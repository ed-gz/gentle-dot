## Default Permission

Use local Apple speech transcription and Vision document recognition in Capri. Microphone permission is requested only when starting a voice command.

- `allow-check-voice`
- `allow-prepare-voice`
- `allow-start-voice`
- `allow-stop-voice`
- `allow-cancel-voice`
- `allow-inspect-retained-voice`
- `allow-discard-retained-voice`
- `allow-export-incomplete-voice`
- `allow-attach-retained-voice`
- `allow-prepare-retained-voice`
- `allow-list-voice-receipts`
- `allow-get-voice-receipt`
- `allow-discard-voice-receipt`
- `allow-release-retained-voice`
- `allow-recognize-document`
- `allow-cancel-document`
- `allow-scan-pairing-code`
- `allow-cancel-pairing-code`
