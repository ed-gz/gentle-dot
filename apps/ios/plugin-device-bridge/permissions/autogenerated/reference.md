## Default Permission

Use iPhone Keychain, explicit authenticated requests, pairing, OAuth, secure hashes, locally shared files, and explicit document export.

- `allow-secret-get`
- `allow-secret-set`
- `allow-secret-delete`
- `allow-pair-device`
- `allow-unpair-device`
- `allow-https-request`
- `allow-oauth-authorize`
- `allow-oauth-cancel`
- `allow-open-external-url`
- `allow-registered-url-schemes`
- `allow-crypto-random`
- `allow-crypto-sha256`
- `allow-crypto-hash-begin`
- `allow-crypto-hash-update`
- `allow-crypto-hash-finish`
- `allow-crypto-hash-cancel`
- `allow-share-list`
- `allow-share-read`
- `allow-share-ack`
- `allow-export-begin`
- `allow-export-write`
- `allow-export-present`
- `allow-export-cancel`
