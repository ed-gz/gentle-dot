# Historial de sesiones en iPhone

Capri conserva páginas ya vistas en memoria mientras la vista está abierta, pero no las presenta de nuevo tras cambiar de sesión, sección o volver de segundo plano hasta recibir una inspección actual. Sólo concatena el historial anterior si el host identifica la misma instancia del proceso. Una página tardía de una instancia diferente se descarta y no cambia el cursor. Si el host no proporciona identidad de instancia, el historial reciente sigue legible y se explica que hay que actualizar la laptop para cargar páginas anteriores con verificación.

El modo desktop compartido conserva su comportamiento anterior. Esta garantía se probó con sesiones simuladas y no prueba un iPhone ni la laptop desplegada. Las imágenes históricas siguen representándose mediante un aviso: el transporte de sesiones del iPhone pide una proyección de texto para respetar su límite de respuesta y todavía no tiene una vía para recuperar esas imágenes.
