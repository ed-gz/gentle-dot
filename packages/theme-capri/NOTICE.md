# Capri theme notice

This package is Eduardo Garza's optional personal customization for Gentle Dot. It is not the upstream Gentle Dot identity and is disabled by default. The application works with its original Gentle Dot appearance and persona without enabling this package.

The Capri and Rebecca artwork is fan artwork inspired by Cyberpunk: Edgerunners. Character and franchise rights remain with their respective owners; this package claims no ownership of those characters, no official status and no endorsement. The repository's software license does not grant rights to the underlying characters or trademarks. This notice does not represent a license from their owners.

The production PNG sprite sheets were generated using the integrated OpenAI image generation tool. The accompanying JSON files describe the original image crops, registration offsets, timing and transparency. They are included locally; enabling the theme does not generate images, contact an image service or download external artwork.

`provenance/` retains the generation instructions with local machine paths removed. Copied reference screenshots, rejected drafts and non-runtime reference images are excluded. Public reference links document artistic provenance and are never loaded at runtime.
